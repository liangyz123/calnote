# 日历便签 v9 · 第 3 期：密码本（保险柜）

抽屉（右上角 ☰）里新增「🔐 密码本」。这期是三个功能里安全边界最重的一期，所以把设计取舍和做不到的地方都写明白。

## 一、必须先知道的一条

**主口令忘了就是永久打不开，没有任何找回通道。** 因为服务器上确实只存了「派生之后的校验值」，没有任何地方能反推你的主口令——这正是加密要的效果，也意味着没人在背后留了后门。

配套的两句话：

- 备份 = `data/calnote.db` + 你的主口令，**两样缺一不可**。只拷走库文件等于拷走一把没有钥匙的锁；只记得主口令但 `data/` 丢了，密码本就空了。
- 建议第一次设完，先在纸上抄一份收好。别和别的网站用同一个口令。

首次进入会让你设主口令（至少 8 位）。设好之后，**登录便签 ≠ 打开密码本**：每次进密码本要再输一次主口令，解锁后默认保持 30 分钟（`VAULT_SESSION_MIN` 可调），超时或点「立即上锁」就要重输。

## 二、加密是怎么做的

- 每条内容的**每个字段单独加密**（名字、网址、账号、密码、备注），算法 **AES-256-GCM**。
- 密钥由 `主口令 + 每个用户独立随机盐` 经 **scrypt**（N=32768, r=8, p=1）派生，约 32MB 内存 / 85ms，NAS 上完全跑得动；机器紧张可以设 `VAULT_KDF_N=16384`。
- 库里只存盐、scrypt 参数和一个 HMAC 校验值，**不存主口令、不存密钥**。验收时我直接从 `calnote.db` 的二进制内容里搜主口令、搜派生密钥、搜密码明文，都搜不到。
- 密文用每行的随机 `ref` 做绑定（GCM 的附加认证数据），把某一行的密文挪到另一行会直接解不开，列表里会明确显示「解不开：密文或密钥有问题」而不是静默变成空白。
- 依赖 `cryptography`（已写进 `requirements.txt`，版本按实测钉在 50.0.2，有预编译轮子，NAS 构建不用自己编译）。**没有自己实现任何密码算法**——标准库里没有对称加密，自研这一块是真正的风险所在。

## 三、共享与私有（这一条请务必看懂）

默认所有条目都是**私有**：只有你的主口令能解，家人看不到，管理员也解不开。

但家庭场景确实有「WiFi 密码、视频会员」这种要全家共用的。这里有个绕不开的技术事实：密文是用各自主口令派生的密钥加的，别人没有你的主口令，就永远解不开你的条目——想共享就必须有一个大家都能用的密钥。所以：

- 勾了「共享给家里其他人」的条目，**改用服务器上的 `data/vault_share.key` 加密**。
- 代价说清楚：**共享条目的保密性只依赖服务器文件安全，不再受你的主口令保护**。任何能登录便签的人，解锁自己的密码本后就能看到这些条目（包括密码）。
- 因此界面上勾选框写的是「勾了就等于全家可见」，默认不勾。WiFi 密码这类你愿意全家知道的再勾。
- 别人共享过来的条目，在你这里会标「共享 · 来自别人」，且不能改不能删（只有建的人能改）。
- 私有 ↔ 共享来回切换会自动换密钥重加密，实测两个方向都不丢数据。

**一条设计缺陷被抓到并修好了**：原本解密时「先按本人主口令」判断，导致**你自己创建的共享条目反而解不开**（它用的是服务器密钥），列表里会显示成损坏；同时「改主口令」会试图用旧口令解密全部条目，一撞上共享条目就整体中止、主口令永远改不掉。现在都改成「先按是否共享选密钥」，改口令只重加密私有条目，失败还会整体回滚不动数据。

## 四、防外泄的几道闸

- **列表接口永远不带密码字段**，只有 `has_pass` 这个布尔标记；点「显示密码」才发一条单独的 `reveal` 请求，响应带 `Cache-Control: no-store`，不进 Service Worker、不进浏览器缓存。
- **解锁按设备**，不是按账号：凭据是「账号 + 这台设备的 sid」，sid 只放 `sessionStorage`（刷新还在，关掉标签页就没了）。否则手机上解锁一次，电脑上同一账号就直接通了。
- 界面上有「立即上锁」，只锁当前这台设备，不影响你另一台。
- 改主口令后，这个账号**所有设备**都要重新解锁。
- 连续输错主口令 8 次锁定 5 分钟（`VAULT_FAIL_LIMIT` / `VAULT_LOCK_SEC`），锁定期间**就算输对也拒绝**。
- 共享条目被谁看过会留痕，你进「谁看过我的」能查；自己看自己的不记。管理员能看全局留痕。
- 密码显示后 30 秒自动收起。复制到剪贴板：https/本机用系统剪贴板 API，**内网 http 访问会自动退回兼容写法**（这点特意测了，因为你的主用法就是 `http://NAS_IP:8000`）。但要说实话：浏览器不允许网页替你定时清空剪贴板，所以只能提示你用完自己清，**我不会假装这个能做到**。
