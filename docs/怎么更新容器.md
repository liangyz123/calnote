# 怎么更新容器（三种玩法，任选一种）

## 玩法 1：一条命令搞定（推荐）
1. 把新包 `calnote-v6.6.zip` 和这个目录放一起（NAS 文件管理里拖进去就行，比如放在
   `/vol3/1000/01资料/calnote/` 里，和你现有的 app.py、data/ 同一层）。
2. SSH 登录 NAS，执行：
   ```bash
   cd /vol3/1000/01资料/calnote
   sh update.sh calnote-v6.6.zip
   ```
   它会：备份 `data/calnote.db` → 解压覆盖代码（**只覆盖代码，绝不碰 data/attachments、data/import**）
   → `docker compose build` → `up -d` → 访问一次 `/api/health` 自检；
   **自检不通过会自动回滚到上一次的镜像**，并把日志尾巴打给你（截图发我就行）。
3. 手机重开一次「千问便签」即可（样式缓存号会换）。

不带包名 = 只按当前目录里的代码重建：
```bash
sh update.sh
```

## 玩法 2：飞牛 Docker 界面点鼠标
1. 文件管理里把 `app.py`、`static/`、`tools/`、`Dockerfile`、`docker-compose.yml` 覆盖到 calnote 目录（弹提示选"替换"）；**`data/` 不要动**。
2. Docker → 项目（Compose）→ calnote → **构建/重新部署** → 完成后 **启动/重启**。
3. 界面里没有"构建"按钮时：容器列表 → calnote → 停止 → 删除容器（**不要删卷/数据**）→ 回到项目再点"部署/启动"。

## 玩法 3：全自动（每天自己更新 + 自己刷天气）
飞牛「任务计划 / 计划任务」里新增 Shell 脚本任务：
```bash
cd /vol3/1000/01资料/calnote && sh update.sh >> data/update.log 2>&1
```
- 定时：例如每天 04:30（避开你在用的时段）
- 天气也想自动刷成实测值的话，再加一条（同一个目录，每天一次就够）：
```bash
cd /vol3/1000/01资料/calnote && docker compose exec -T calnote python tools/refresh_weather.py --apply >> data/weather.log 2>&1
```
> 提醒：`update.sh` 每次都会留一份 `data/calnote.db.bak-日期`，默认最多留 10 份，改这个文件顶部 `KEEP=10` 就行。
>
> v9 起这份备份改成 **SQLite 在线快照**（`VACUUM INTO`），因为开了 WAL 后直接 `cp` 可能漏掉
> 还没并回主文件的最近几分钟事务。万一你的机器上既没有 `sqlite3` 命令、容器当时又没在跑，
> 脚本会退回拷贝并同时留一份 `.bak-时间-wal` —— 那种情况下回滚要**两份一起放回**：
> `cp data/calnote.db.bak-那个时间戳-wal data/calnote.db-wal`

## 出问题怎么退回去
```bash
cd /vol3/1000/01资料/calnote
ls -1t data/calnote.db.bak-* | head -3          # 看最近几份备份
cp data/calnote.db data/calnote.db.broken-$(date +%H%M)
cp data/calnote.db.bak-那个时间戳 data/calnote.db
docker compose up -d
```
