# 微信 / 支付宝账单导出与导入（日历便签记账）

> 便签这边：**记账 → 导入账单**，直接选文件 → 先「预览」（不动数据）→ 确认后勾上「直接写入」再点一次。
> 三种都认：微信导出的 **xlsx**、支付宝导出的 **csv / xlsx**、以及本应用「导出CSV」的文件（可以再导回去合并）。
> 自动跳过：交易关闭、已全额退款、退款成功；重复（同日+同金额+同方向+备注前缀）不重复入。

## 一、微信（手机端）

1. 打开 **微信 → 我 → 服务 → 钱包 → 账单**（新版本叫「钱包 → 账单」，右上角有「常见问题」旁边那个）。
2. 右上角 **「…”→ 下载账单 / 导出账单明细」**（有的版本叫「账单管理 → 导出账单」）。
3. 选时间范围（一次最多一年），用途选 **「个人对账」**，邮箱填自己的。
4. 收到邮件后**在手机上用系统邮件/浏览器打开附件链接**，下载到手机（会得到一个 `微信支付账单流水文件(xxxx-xx-xx)_xxxx.xlsx`）。
   - ⚠️ 关键坑：邮件里的"解压密码"是给你的 PC 解压 zip 用的；如果你拿到的直接是 `.xlsx`，那就是已经解好的，便签能直接读。
   - 如果只拿到 `.zip`：用手机的文件管理长按解压，或电脑上解压出 xlsx 再传进 NAS。
5. 便签「导入账单」→ 选这个 xlsx → 看预览笔数对不对 → 勾「直接写入」→ 完成。

**电脑上看得到表头长这样**（便签就是按这几个字认列的，你的文件如果列名不同，告诉我我加别名）：
`交易时间 | 交易类型 | 交易对方 | 商品 | 收/支 | 金额(元) | 支付方式 | 当前状态 | 交易单号 | 商户单号 | 备注`

## 二、支付宝（手机端）

1. **支付宝 → 我的 → 账单** → 右上角 **「…” → 开具交易流水证明 / 下载账单」**。
2. 用途选 **「个人对账」**（选"用于个人对账"才会给明细表格；选"证明材料"给的是 PDF，不能导），选时间范围，填邮箱。
3. 邮件里得到 `支付宝交易明细(xxxx-xx-xx).csv`（也可能是 xlsx；压缩包同样要解压）。
4. 便签里同样是「导入账单 → 选文件 → 预览 → 写入」。

表头：`交易时间 | 交易分类 | 交易对方 | 对方账号 | 商品说明 | 收/支 | 金额 | 收/付款方式 | 交易状态 | 交易订单号 | 商家订单号 | 备注`

## 三、导入之后建议做的三件事

1. **管分类**：微信/支付宝给的分类只会归到便签的「其他/餐饮/交通…」这类，导入后到 **记账 → 管分类** 里把名字、图标（一个 emoji）改顺手；顺序数字小的排前面。
2. **删掉不想要的**：流水每行右侧 `✕` 删除，先进「记账垃圾桶」（**记账 → 🗑 桶**），30 天内可 `↩ 恢复`。
3. **账户归属**：导入时顶上选的「记到哪个账户」就是这批流水花出去的钱从哪个口袋出（现金/微信/银行卡…），选错了可以逐笔点 `✎` 进编辑卡片改。

## 四、对不上时的排查顺序

| 现象 | 原因 / 处理 |
|---|---|
| 提示"读不了 xlsx，没装 openpyxl" | 你换包后没 `--build`：`docker compose up -d --build`（openpyxl 很小，构建不会像上次装 ffmpeg 那样卡住） |
| 「没找到表头行」 | 你拿到的是 PDF 回单/证明材料；重新导出，用途选**个人对账** |
| 预览笔数比微信说的少 | 少掉的就是「交易关闭 / 已全额退款」，本来不该入账（提示里的"不适用 N"就是它） |
| 分类都进了「其他」 | 正常：微信的"交易类型"和便签分类名不一样。导完在「管分类」改；或者告诉我它的类型都有哪些，我给你做一份固定映射 |
| 金额是负数 / 位置不对 | 截图给我看两行真实数据（金额可以改成假的），我调列映射 |
