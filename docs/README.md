## ✨ v5 新增 / 修复

- **搜索内容**：顶部 🔍（电脑上按 `/`）进入，关键字同时搜标题、正文、标签、地点、天气，可按「笔记/日程/生日/纪念日/待办/倒数日」筛选，结果里命中的字会高亮，点一条直接跳到那天的详情并打开编辑。原来是把全库读进浏览器再过滤，导入几千条后会卡死；现在改成服务端查询 + 分页。

## 📱 快速访问图标（做到桌面上）

应用本身是 PWA（`static/manifest.webmanifest` + `sw.js` + `icon-192/512.png` 都齐了），装到桌面/主屏就有独立图标，点开即用、不带浏览器地址栏。

**关键前提：浏览器的 PWA「安装」只在安全上下文里开放——也就是 `https://` 或 `localhost`。** 局域网用 `http://192.168.x.x:8000` 直接开，桌面 Chrome/Edge 的安装按钮常常是灰的或不出现。所以两条路：

- **走 fnOS 的 HTTPS 入口（推荐）**：飞牛 **设置 → 安全/域名服务（DDNS + 证书）** 里开启内置域名访问（fnOS 会自动签 Let's Encrypt 证书），得到类似 `https://xxxx.fnnas.com:8444` 的地址；然后在 **Docker → 容器 → 端口/反向代理设置** 或飞牛的 **网络/反向代理** 里把 calnote 的 8000 端口挂到一个 HTTPS 路径下。用这个 `https://` 地址打开一次，安装入口就会出现：
  - **电脑 Chrome/Edge**：地址栏右侧的「安装」图标，或菜单 → **保存并分享 / 应用 → 将此站点安装为应用**。装完在开始菜单/桌面有「日历便签」图标，独立窗口、可固定到任务栏和 Dock。
  - **安卓 Chrome / Edge**：菜单 **⋮ → 添加到主屏幕**（HTTPS 下会显示「安装应用」），桌面生成图标。
  - **iPhone Safari**：分享 → **添加到主屏幕**（iOS 的 PWA 要求 HTTPS + manifest，用 fnOS 的 https 域名即可，图标用 `apple-touch-icon` 指向的 PNG）。
- **不想折腾 HTTPS**：手机/电脑浏览器菜单里的「添加到主屏幕 / 创建快捷方式」仍然可用（本质是带地址栏的书签），或者用下面「飞牛桌面/肉桂桌面图标」那节，都不要求 HTTPS。也可以用 Tailscale/ZeroTier 给 NAS 一个能用的 https 内网域名后走 PWA 安装。

### 1) 肉桂 / Cinnamon 桌面启动器（最省事）

你自己那台飞牛底层装了 Cinnamon（肉桂）桌面，最省事的是直接在桌面做一个启动器图标：

```bash
# 在肉桂桌面上打开终端，指向 NAS 的访问地址
bash tools/desktop-icon.sh http://192.168.1.20:8000
```

脚本会：把应用自带图标 `icon-512.png` 下到 `~/.local/share/icons/calnote.png`；在 `~/桌面`（或 Desktop）和「应用菜单」各生成一个启动器；浏览器优先用 `chrome/chromium --app=地址 --class=calnote` —— 打开后没有地址栏和标签页，看起来就是独立应用，可以右键任务栏「固定到任务栏」，也能在 Cinnamon 的菜单里搜到「日历便签」。（只有 Firefox 时退化成 `--kiosk`。）双击首次提示不信任时：右键图标 → 允许运行/允许启动。

### 2) 想让图标出现在「飞牛桌面」上

- **WatchCow（飞牛专用）**：Docker 里跑一个 WatchCow 容器，它会扫描本机其它容器并在**飞牛桌面**自动生成图标，点图标直接跳到该容器的端口页面 —— 不想改 HTTPS、又想让所有自建应用都在飞牛桌面上有入口，用这个最整齐。给它加个只读挂载 `-v /var/run/docker.sock:/var/run/docker.sock:ro` 即可。
- **fndesk**：飞牛的桌面美化/图标管理工具（可应用中心安装，也能 Docker 部署），图标、文件夹、外链都能自己排；想把「日历便签」和别的自建应用一起归类整理时用。
- **fnOS 自带（V0.8.36 起）**：系统设置 → 应用，可以给应用图标设置访问端口、访问路径、自定义 URL。这一项主要面向**应用中心安装**的应用；Docker 自己起的容器要让飞牛桌面出现图标，还是上面 WatchCow/fndesk 更直接。

浏览器地址栏右侧那个「安装应用」按钮只在 **HTTPS（或 localhost）** 下出现，所以内网 `http://IP:8000` 看不到属正常现象，别怀疑部署有问题。用上面「桌面图标」那条（`desktop-icon.sh`）在肉桂桌面上效果等同于装好的 App。

想让图标更好看：换掉 `static/icon-192.png` / `icon-512.png`（正方形 PNG，512 那张四周留点空白，manifest 里已声明 `purpose: any maskable`），换完强刷一次，或把 `static/sw.js` 里的 `calnote-v5` 改成 v6 让缓存整体失效。

