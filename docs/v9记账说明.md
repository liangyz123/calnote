# 日历便签 v9 · 第 2 期：记账

第 1 期的账号地基装好之后，这期加上记账。数据全部落在你自己 NAS 的 `data/calnote.db` 里，没有外部服务、没有云端。

## 一、怎么用

**入口**：抽屉（右上角 ☰）里新增「💰 记账」；日历上点任何一天，当天信息下面还有一行「今天 支 xx.xx ＋记一笔」，手机上记日常开销两步就够——点「＋记一笔」，输金额，点「记下」。

**记一笔**支持三种方向：

- **支出**：金额 → 分类 → 账户 → 记下。分类和账户都默认选中第一个（现金 / 餐饮），改一下就行。分类里没写过的名字，接口允许直接传新名字并自动建类。
- **收入**：工资、报销这类，单独一类，不会混进支出。
- **转账**：例如「银行卡 → 微信 500」。转账**只动两个账户的余额，不进支出统计**——这是记账最容易算错账的地方，一开始就按双分录做了。

**账本页**里有：月份切换、账本切换、本月支出/收入/结余（带比上月多或少百分之几）、每个账户的余额卡、分类占比条、流水明细（点一条可以改金额和备注，删除也在这里）。「＋账户/分类」加自己的类别，「＋账本」另开一本（比如厂里、学费）。

**第一次进账本页就可用**：自动给你建好一本「日常」，含现金 / 微信 / 支付宝 / 银行卡四个账户，餐饮、交通、购物、居住、医药、通讯、娱乐、人情、工作、其他十个支出分类和工资、兼职、报销、其他收入四个收入分类，不用先搭结构。

## 二、和日历怎么联动

不往 `items` 表里复制副本（同一笔钱存两处迟早对不上）：

- `/api/day` 多带一个 `ledger`：当日支出、收入、笔数、明细，显示在当天信息下面。
- `/api/items?month` 多带一个 `ledger_daily`：当月每天的收支，日历格子右下角标出当天花了多少（如 `-86`），没有支出但有收入时标 `+`。
- 统计全部走一次 `GROUP BY`，`entry` 表建了 `(book_id, day)` 等 8 个索引，实测 `summary`、`entries`、`setup` 各约 2-3 ms，没有逐条查询。

## 三、金额一律按「分」存

数据库里存整数分（`cents`），接口只接受 `12`、`12.3`、`12.34` 这类写法并**用字符串解析**，全程不经过浮点。所以 `0.1 + 0.2` 记两笔就是 `0.30`，不会出现 `0.30000000000000004` 之类的合计对不上。这条如果一开始用浮点存，以后要重算全部流水才能修，所以第一期就定死了。

## 四、谁能看谁的账

账本权限按人隔离，和「笔记私有」是同一套思路：

- 每人第一次进账本页，自动有一本**自己的**「日常」；`jiaren1` 的账，`calnote` 看不到，反之也一样（`/api/ledger/summary?book=别人的` 直接 404）。
- 要一家人记同一本账：把成员加进同一个账本即可（`/api/members` 拿 id，PUT 账本时带 `members`）。共享账本里，别人记的那笔会标出是谁记的。
- 账本成员权限留了 `rw` / `r` 两档，只读成员能看不能记（界面上暂时都按可写给你建，需要只读随时让我加开关）。
- 有流水的账户和分类**不允许删**，会提示「这个账户已经有 N 笔流水」——不然历史账会变成没归属的孤儿数据。
